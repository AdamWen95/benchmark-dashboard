# 数据使用说明

本项目的源码、数据 API、分析服务和本地运行产物是不同的对象。获得 API Key 或成功调用接口不能单独证明所有展示、缓存、再分发和第三方处理用途均获许可。公开仓库不包含账号合同、内部使用审批或真实调用记录。

使用者应根据自己的账号方案和实际用途核对以下范围：

| 用途 | 需要核对的范围 |
| --- | --- |
| 调用 Artificial Analysis API | 账号方案、请求限制、适用协议和凭据管理 |
| 保存本地快照与 SQLite | 缓存范围、保留周期与删除要求 |
| 多人展示或内网服务 | 展示对象、访问范围、数据共享和再分发条件 |
| 长期历史归档 | 历史留存期限、服务终止后的处理要求 |
| 向分析模型发送必要事实 | 发送范围、分析服务方条款和数据处理要求 |
| 公开网页、下载文件或公共 API | 对外发布和再分发的适用条件 |

页面标注 Artificial Analysis 来源并保留原始字段、采集时间和必要限制。缓存机制与来源标注只是项目行为，不代替适用于使用者的许可判断。

可供核对的官方资料：

- [Artificial Analysis API 文档](https://artificialanalysis.ai/api-reference)
- [Data Platform Terms](https://artificialanalysiscdn.com/legal/ProDataPlatformTerms.pdf)
- [Terms of Use](https://artificialanalysis.ai/docs/legal/Terms-of-Use.pdf)

这些链接用于使用者核对当前条款，本文件不声称已审查某个账号或适用于所有场景。

## 配置和请求

`.env` 是本地明文配置，由执行采集或分析的程序读取，不应提交、共享或打印。数据 API Key 与分析 API Key 分开维护。网页和离线预览不读取密钥；计划任务的 `--check` 模式在本地校验凭据但不联网。

配置模板中的分析与日更开关默认关闭。复制模板、启动网页或运行测试不会授予或触发真实请求。显式采集、分析和调度需要使用者配置自己的凭据、确认用途并主动启用；本仓库不附带任何历史授权额度。

可选 Modex 适配器发送程序整理的必要指标、差异、覆盖与限制，使用固定服务端点及模型配置。真实传输前应检查输入范围和费用条件；返回正文仍需人工复核。

## 运行产物

`data/`、`reports/`、日志、真实配置和部署备份均属于本地产物，已被 `.gitignore` 排除。它们可能包含源数据、模型映射、完整简报、内部地址或操作记录，不能仅凭没有密钥就视为适合公开。

分析结果有效期只影响当前展示，不自动删除文件。部署者负责设置并执行适当的保留策略。维护时保留数据库、日期与作用域记录、尝试标记及历史依据；不要通过删除标记重新发起已经尝试过的请求。
