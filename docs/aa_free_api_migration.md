# Artificial Analysis 免费 API 迁移

核对日期：2026-11-02。依据：[迁移公告](https://artificialanalysis.ai/data-api/migrate-v2-data)、[新接口文档](https://artificialanalysis.ai/data-api/docs/reference)、[数据约定](https://artificialanalysis.ai/data-api/docs)。

## 使用范围

采集固定使用 `GET /api/v2/language/models/free` 和已有 `x-api-key`，不申请或购买 Pro，不自动切换端点。旧地址只用于识别已有快照，不再联网调用。官方旧接口截止时间为北京时间 2026-11-05 07:59。

免费版展示综合智能指数、六项行业能力指数、输入/输出价格，以及 `performance` 内四项性能中位数。完整响应耗时按官方默认 500 回答 Token 解释。Coding/Agentic 指数已停止发布；旧数学指数、完整单项评测和混合价格不作为免费版当前指标。未知字段保留原文，不自动进入分析。

评测配置、日期和免费性能工作负载缺失时保持未知。指数原值不转百分比；新字段单位不反向覆盖旧字段核验结论。缺失不补零，性能零值不参与优劣判断。

## 分页与预算

每日仍只有一批采集，沿用原日期、grant 和互斥锁。一批最多 10 次 HTTP 请求（含手动入口可能发生的重试）；正常日更每页一次，失败即停止，不当天重试、不补跑。最多接受 10 页、每页 1,000 条；超限、页码/总页数/页大小漂移、套餐或指数版本变化、重复 ID、缺页均拒绝整批。429 直接停止，不立即重试。

分页是一批完整采集的必要组成。`acquisition_runs.attempts` 和日更结果记录实际 HTTP 请求次数；日期锁的 `collection_attempts=1` 表示当日批次已消耗，重启不恢复额度。每次请求沿用连接/读取超时 10/45 秒。

## 历史与比较

不改 SQLite 表结构，不重写旧数据库、快照、哈希或简报。新快照使用 `api_contract=aa-language-free-v1`，保存原始分页 `api_pages`、汇总数据、套餐及指数版本。原始哈希继续包含完整正文；日更另外比较模型内容，避免分页布局或套餐信息变化触发 AI。

首次切换协议或智能指数版本变化时，保留前后证据并建立新基线：不生成批量下架、转缺失或能力涨跌事件，该批次不请求 AI。下一次同口径成功采集恢复正常比较。

离线测试使用合成分页、临时 SQLite 和 Streamlit AppTest。发布前核对远端文件，备份实际改动文件及数据库，再增量部署；保留 .env、业务数据、历史尝试记录和服务保护。不运行日更 `--execute` 做测试，真实 API 验收依赖下一次正常日更。

应用恢复使用本次文件备份；没有数据库结构迁移，不需要回填。已有新协议快照不可用旧解析器作完整业务验收；停用日期后旧客户端无法恢复采集。恢复时保留新快照和当天尝试记录，不能恢复旧库来重获额度。
